How to enable model access for an API key

  1. Open Users and click Issue key beside the user.
  2. Enter a key name, then select one or more model checkboxes.
  3. Copy the secret when it appears—it is shown only once.
  4. To change access later, return here and click Models beside the key. Changes take effect immediately.

A model must also be enabled on the service through LAYA_ENABLED_MODELS before it can be assigned.
